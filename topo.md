# Топология – Сесия 1

## Машини

| VM  | vCPU | RAM   | Мрежови адаптери                          |
|-----|------|-------|--------------------------------------------|
| gw  | 1    | 1 GB  | WAN (NAT), LAN1 (192.168.10.1/24), LAN2 (192.168.20.1/24) |
| srv | 2    | 4 GB  | LAN1 (192.168.10.10/24)                     |

Потребител на двете машини: `student` / `tues`

## Сегменти

- **WAN** – VirtualBox NAT адаптер на `gw` (adapter 1), достъп до интернет.
- **LAN1** – VirtualBox internal network `lan1_net`, между `gw` (192.168.10.1)
  и `srv` (192.168.10.10).
- **LAN2** – VirtualBox internal network `lan2_net`, само на `gw`
  (192.168.20.1), без друга машина в момента.

## Маршрутизация

- `net.ipv4.ip_forward = 1` е включен на `gw`.
- `iptables` MASQUERADE на `gw` за трафик, излизащ през WAN интерфейса,
  за да могат LAN1/LAN2 да излизат в интернет през `gw`.

```
                +-------------------+
   Internet ----| WAN         |     |
                |            gw     |
                | LAN1  |  LAN2     |
                +---+--------+------+
                    |        |
              192.168.10.0/24  192.168.20.0/24
                    |
                 +--+--+
                 | srv |
                 +-----+
```

## Проверки (виж чеклиста)

- [ ] `gw` и `srv` стартират и имат различни hostname и адреси
- [ ] `srv` има ping до `gw` (192.168.10.1)
- [ ] `gw` има достъп до интернет
- [ ] IP forwarding на `gw` е включен
- [ ] Топологията е описана тук (`artefakti/s01-laboratoria/topo.md`)
